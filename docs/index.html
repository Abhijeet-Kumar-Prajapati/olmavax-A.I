What makes it different

Built from scratch with plain Node and vanilla JavaScript. Nothing to install, nothing to configure.

🎙️

Voice that shares the chat

Voice floats as a dock above the composer instead of taking over the screen. Speak, hear the reply, and keep typing — all at once.

🧩

19 local plugins

Calculator with roots and percentages, unit converter, text tools, colour, dates, passwords. They run on your server, not through a model.

🧠

Memory that sticks

Facts you tell it are stored and recalled across conversations. Nothing is sent anywhere to make that happen.

📅

Scheduled tasks

Cron-style jobs that run a prompt on a timer, so the workspace works while you are away.

🎨

Syntax highlighting

Twenty-two languages, written from scratch and XSS-safe. No CDN, no third-party highlighter.

📐

A sidebar that fits

Icon rail, small, medium or large. The chat history stays reachable at every single size.

Works with nothing

Clone it, run it, use it. A provider key is optional.

Quick start

Requires Node.js 18 or newer. That is the only requirement.

# clone
git clone https://github.com/Abhijeet-Kumar-Prajapati/olmavax-A.I.git
cd olmavax-A.I

# run - there is nothing to install
npm start

# then open
http://127.0.0.1:8787
This page is the project website, not the app. GitHub Pages only serves static files, so Olmavax A.I runs on your own computer. Add a provider key in Settings to talk to Claude, GPT or Ollama — without one, the built-in offline brain still answers.
